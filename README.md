# Catálogos VONDER

Página estática de acesso rápido aos catálogos VONDER. Os PDFs são abertos e baixados diretamente do servidor oficial da OVD; este repositório não armazena os PDFs.

## Publicação em VPS

Envie o conteúdo da raiz deste repositório para a raiz pública do site, por exemplo `public_html/`. Não precisa de PHP, Node.js nem etapa de build.

A pasta `pdfs/` contém somente as miniaturas JPG das capas.
